# Visual asset notes

The PNG artwork under `assets/` was created for this project with OpenAI's built-in image-generation tool. The assets are original and were generated without using Phoenix HD artwork as image input.

## Final prompt set

All prompts required an isolated cutout with genuine transparency, no text, no logo, no watermark, no UI, no existing-game design, a clean silhouette, and complete uncropped geometry.

1. **Player interceptor:** Original top-down orthographic elite interceptor for a premium vertical shooter; bilateral symmetry; swept wings; silver titanium armor; cyan energy channels; amber reactor; panel seams and battle wear; polished physically based 3D game sprite.
2. **Enemy scout:** Original top-down hostile light interceptor pointing downward; compact predatory silhouette; gunmetal armor; crimson reactor and warning lights; vents and weapon ports; polished physically based 3D game sprite.
3. **Heavy gunship:** Original top-down armored gunship pointing downward; broad silhouette; bronze and gunmetal layered armor; side cannons; orange reactor; heat staining and battle wear; polished physically based 3D game sprite.
4. **Boss dreadnought:** Original top-down alien-mechanical capital ship pointing downward; black titanium and burgundy armor; huge swept wings; turret hardpoints; mechanical joints; magenta reactor; heat damage; high-detail physically based 3D game sprite.
5. **Fireball:** One isolated irregular turbulent combustion burst; white-hot core, rolling yellow-orange flames, deep red embers and incandescent fragments; realistic pre-rendered cinematic game VFX.
6. **Smoke:** One isolated irregular volumetric charcoal smoke puff; layered billows, soft translucent edges and faint internal ember heat; realistic pre-rendered cinematic game VFX.
